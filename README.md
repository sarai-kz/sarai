# sarai
SARAI — платформа для ремонта и строительства

## Қазақша және орысша нұсқалар

Клиенттік беттің жоғарғы жағындағы `ҚАЗ / РУС` ауыстырғышы тілді бетті қайта жүктемей өзгертеді. Орысша нұсқаны `?lang=ru`, қазақша нұсқаны `?lang=kk` арқылы тікелей ашуға болады. Таңдау браузерде сақталады; толтырылған формалар мен таңдалған шебер жоғалмайды.

`index.html` ішіндегі аударма модулі мәзірді, формаларды, калькуляторды, күй/қате хабарламаларын және WhatsApp мәтіндерін аударады. Қызметтер мен бастау мерзімдерінің ішкі мәндері қазақша күйінде сақталады, сондықтан ашық JSON жазбаларының пішімі өзгермейді. Клиенттер мен шеберлер енгізген еркін мәтін автоматты түрде аударылмайды.

## Жұмыстарды жариялау

Алғашқы нұсқа SARAI арқылы тексеріп жариялауға арналған:

1. Клиент `Жұмыс жариялау` формасын толтырып, дайын өтінімді WhatsApp-та SARAI-ға жібереді. Форманы толтырудың өзі өтінімді жібермейді және сайтқа жарияламайды.
2. SARAI жұмыс мәліметтерін клиентпен нақтылайды.
3. Тек ашық сипаттама `data/jobs.json` файлына қосылып, сайт жаңартылады. Осыдан кейін жұмысты барлық құрылғыдан көруге болады.
4. Шебердің `Осы жұмысқа ұсыныс беру` хабарламасы жұмыс нөмірімен бірге SARAI-ға бағытталады.
5. Орындалған жұмысқа `status: "closed"` қойылады; ол ашық тізімде көрінбейді.

Клиенттің аты, телефоны, нақты мекенжайы және жеке хабарламалары осы ашық репозиторийге **ешқашан қосылмайды**. Олар WhatsApp-та қалады. Автоматты жариялау, жеке кабинет және ұсыныстарға арналған жеке сілтемелер бұл нұсқада жоқ.

### Ашық жазба пішімі

Түбір: `{"version": 1, "jobs": [...]}`. Нақты тапсырыс жоқ кезде тізім бос болады; үлгілік тапсырыстар жарияланбайды.

Әр жұмыста тек мына өрістер қолданылады:

| Өріс | Мәні |
| --- | --- |
| `id` | Бірегей нөмір, мысалы `SARAI-20261023-001` |
| `status` | `open` немесе `closed` |
| `city` | `Астана` |
| `service` | Сайт формасындағы қызмет атауларының бірі |
| `title` | 8–100 таңба |
| `description` | 20–1200 таңба, тек жұмыс туралы |
| `district` | Аудан/тұрғын үй кешені, 0–80 таңба; көше/үй/пәтер нөмірінсіз |
| `area` | 1–10000 м² аралығындағы сан немесе `null` |
| `budget` | 1–100000000 ₸ аралығындағы бүтін сан немесе `null` |
| `start` | `Келісеміз`, `Мүмкіндігінше тез`, `Бір апта ішінде`, `Бір ай ішінде` |
| `published_at` | Уақыт белдеуі бар ISO 8601 уақыты |

Сипаттамалар HTML ретінде орындалмай, мәтін ретінде көрсетіледі. Күн Астана уақытымен беріледі. Іздеу, қызмет сүзгісі, жаңарту, бюджет және күн бойынша реттеу бар. Клиенттің байланыс деректері үшін қосымша өрістер енгізілмейді.

## Шеберлерді иесінің басқаруы

`admin.html` бетінен шебер қосуға, мәліметін өзгертуге және клиенттер тізімінен жасыруға болады. Әр өзгеріс дайын GitHub issue сұрауын ашады; иесі `sarai-kz` аккаунтымен `Create` басып растайды. `.github/workflows/sarai.yml` сұрауды тек репозиторий иесінің логині, тұрақты пайдаланушы ID-і және әрекет жасаған аккаунт сәйкес келгенде орындайды. Расталмаған форма мәліметі жарияланған тізім болып есептелмейді.

`manage-masters.cjs` тек `masters.json` файлын жаңартады. Күтілген жаңарту уақыты ескірген өзгерісті кері қайтарады, қайталанған сұрау екінші жазба қоспайды, қатар келген сұраулар файл SHA-сы арқылы тексеріледі. Клиенттік бет тек `active: true` карточкаларын көрсетеді. Басқару формасын ашу жариялау құқығын бермейді; жазуды GitHub аккаунты және сервердегі workflow тексереді. Сайтта токен немесе ортақ құпиясөз сақталмайды.

GitHub Pages Source параметрі `GitHub Actions` болуы керек. Workflow қалыпты push, қолмен іске қосу және иесінің шебер сұрауынан кейін сайтты жариялайды. Клиенттердің жеке байланыс деректері бұл механизмге берілмейді; мұнда тек жариялауға арналған шебер мәліметтері сақталады.

### SARAI арқылы байланысу

Клиенттік шебер карточкасында тек аты, мамандығы, сипаттамасы және «Осы шеберге өтінім» батырмасы бар. Таңдалған шебер өтінімге қосылады; хабарлама әрқашан SARAI WhatsApp нөміріне жіберіледі. Шеберге тікелей қоңырау немесе WhatsApp сілтемесі берілмейді.

Шеберлердің телефондары SARAI иесінің WhatsApp-ында сақталады. `masters.json` тізімінің 2-нұсқасы мен GitHub-тағы жариялау сұраулары телефон өрісін қабылдамайды; аты мен сипаттамасында телефон, сыртқы сілтеме немесе email болса, жариялау тоқтатылады. Жаңа шебер қосу үшін аты, мамандығы және қажет болса жұмыс сипаттамасы жеткілікті. Ескі 1-нұсқадағы сұраулар қабылданбайды: басқару бетін жаңарту қажет.

Шебермен комиссия сомасын және төлеу мерзімін SARAI жеке келіседі, жұмыстың орындалуы мен төлемін өзі бақылайды. Сайт автоматты комиссия ұстамайды. Бұрынғы репозиторий тарихы мен ескі GitHub сұраулары осы өзгеріспен өшірілмейді.

Тексеру: `node master-management.test.cjs`.
